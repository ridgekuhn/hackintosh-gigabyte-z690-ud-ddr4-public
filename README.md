## Hardware

* Gigabyte Z690 UD DDR4
* Intel Raptor Lake Core i7 14700
* Crucial Ballistix 2x8GB 3200 MHz DDR4 RAM
* Samsung 970 EVO
* Sapphire Nitro+ AMD Radeon 6650 XT
* Fenvi T919

## Software

* Gigabyte Z690 UD DDR4 BIOS F34a
* [OpenCore](https://github.com/acidanthera/OpenCorePkg) 1.0.8
* [OpenCore Legacy Patcher](https://github.com/dortania/OpenCore-Legacy-Patcher) (for Fenvi T919)
* MacOS Sequoia 15.7.7

## BIOS

### Disabled:

* CFG Lock
* CSM Support
* Fast Boot
* Intel Platform Trust Technology (PTT)
* Internal Graphics
* Secure Boot
* Serial Port

### Enabled:

* Above 4G Decoding
* VT-d
* Hyper-Threading Technology
* Intel (VMX) Virtualization Technology
* Re-Size BAR Support
* XHCI Hand-Off

### Misc:

|                     |             |
|---------------------|-------------|
| Internal Graphics   | PCIe 1 Slot |
| Windows 10 Features | Windows 10  |
